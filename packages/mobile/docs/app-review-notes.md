# App Store / Play Store 심사 노트

## 앱 설명
Crew는 기업용 업무 메신저입니다. 회사별 전용 서버에 접속하여 팀원과 실시간 채팅, 파일 공유, 일정 관리, 프로젝트 관리를 할 수 있습니다.

## 계정 생성·로그인·삭제 방식
Crew는 회사 직원만 사용하는 업무 앱이며, 앱 안에서 계정을 직접 만들 수 없습니다 (회원가입 기능 없음).
- **계정 생성**: 직원이 입사하면 소속 회사의 관리자가 계정을 만들어줍니다.
- **로그인**: 첫 화면에서 회사가 알려준 서버 주소를 입력한 뒤, 회사가 발급한 아이디와 비밀번호로 로그인합니다.
- **계정 삭제**: 앱에서 계정을 만들지 않으므로 삭제도 관리자가 처리합니다. 직원이 퇴사하거나 개인정보처리방침에 안내된 담당자에게 요청하면 계정 접속을 차단하고, 법정 보관 기간이 지나면 데이터를 삭제합니다.

심사를 위한 테스트 계정:
- **서버 주소**: `https://demo.emax-app.com`
- **아이디**: `(실제 데모 계정 아이디로 교체)`
- **비밀번호**: `(실제 데모 계정 비밀번호로 교체)`

## 서버 주소 입력 안내
로그인 화면에서 "서버 주소" 필드가 있습니다. 이는 각 기업이 자체 서버를 운영하기 때문입니다.
- B2B SaaS 앱으로, 각 회사가 독립된 서버를 가집니다
- 서버 주소는 HTTPS만 허용됩니다 (http:// 입력 시 차단)
- Slack, Microsoft Teams와 유사한 워크스페이스 접속 방식입니다

## 권한 사용 목적
| 권한 | 사용 시점 | 목적 |
|------|-----------|------|
| 카메라 | 프로필 사진 촬영, 사진 첨부 | 사용자가 직접 촬영한 사진을 메시지에 첨부 |
| 사진 라이브러리 | 프로필 사진 선택, 파일 첨부 | 갤러리에서 이미지/파일 선택하여 전송 |

## 기술 스택
- React Native (Expo)
- Socket.io (실시간 메시징)
- Expo Push Notifications (FCM/APNs)

## 앱 목적 및 대상 사용자
Crew는 기업 내부 커뮤니케이션 문제(흩어진 메신저, 이메일, 별도 일정/프로젝트 툴)를 하나의 업무 메신저로 통합해 해결합니다. 대상은 사내 팀원 간 실시간 채팅, 파일 공유, 일정 관리, 프로젝트(칸반/간트) 관리가 필요한 기업 조직입니다. 각 고객사는 자체 서버 인스턴스를 운영하며, 앱은 그 서버에 접속하는 클라이언트입니다.

## 외부 서비스 / 플랫폼 목록
- **자체 백엔드 서버** (고객사별 독립 운영, PostgreSQL + Node.js/Express) — 핵심 기능(인증, 채팅, 파일, 일정, 프로젝트) 전부 처리
- **Socket.io** — 실시간 메시지 송수신
- **Expo Push Notifications (FCM/APNs 경유)** — 새 메시지/멘션 푸시 알림
- **LDAP (선택, 고객사 환경에 따라)** — 기업 내부 계정 시스템과 로그인 연동 시 사용
- 결제/구독, AI, 분석(Analytics) 등 타사 서비스는 사용하지 않음

## 지역별 차이
앱은 지역/국가에 따른 기능 차이가 없습니다. 모든 기능은 접속한 고객사 서버 설정에 따라 결정되며, 지리적 위치 기반 분기 로직은 포함되어 있지 않습니다.

## 규제 산업 / 제3자 보호 자료
해당 없음. 의료, 금융 등 규제 산업 대상 기능이나 제3자 라이선스 콘텐츠를 포함하지 않는 일반 사내 업무 커뮤니케이션 앱입니다.

## Guideline 3.2 관련 소명 (특정 기업 전용 앱 여부)
Crew는 특정 한 기업의 사내 전용 앱이 아니라, Slack/Microsoft Teams와 같은 B2B SaaS 제품입니다. 서버 주소 입력 필드는 "어느 고객사 워크스페이스에 접속할지"를 선택하는 용도입니다. 단, 셀프 회원가입은 제공하지 않으며, 각 고객사 관리자가 직원 계정을 직접 발급·회수합니다. 앱 자체는 누구나 내려받을 수 있는 일반 App Store 배포 대상이며, Apple Business Manager를 통한 자체 배포 대상은 아닙니다.

## 사용자 생성 콘텐츠(채팅/파일) 신고·차단 관련 소명
메시지·파일 공유는 동일 고객사 내에서 관리자가 계정을 발급한 임직원 간에만 이루어지며, 불특정 다수의 공개 소셜 교류를 목적으로 하지 않습니다. 각 고객사 관리자가 구성원 계정과 권한을 직접 관리하므로, 공개 소셜 앱 수준의 신고/차단 기능은 제공하지 않습니다.
