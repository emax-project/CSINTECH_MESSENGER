# App Store / Play Store 심사 노트

## 앱 설명
Crew는 기업용 업무 메신저입니다. 회사별 전용 서버에 접속하여 팀원과 실시간 채팅, 파일 공유, 일정 관리, 프로젝트 관리를 할 수 있습니다.

## 로그인 방법
이 앱은 기업 전용 서버 주소가 필요합니다. 심사를 위한 테스트 계정:

- **서버 주소**: `https://demo.emax-app.com`
- **이메일**: `reviewer@emax-app.com`
- **비밀번호**: `Review1234!`

## 서버 주소 입력 안내
로그인 화면에서 "서버 주소" 필드가 있습니다. 이는 각 기업이 자체 서버를 운영하기 때문입니다.
- B2B SaaS 앱으로, 각 회사가 독립된 서버를 가집니다
- 서버 주소는 HTTPS만 허용됩니다 (http:// 입력 시 차단)
- Slack, Microsoft Teams와 유사한 워크스페이스 접속 방식입니다

## 권한 사용 목적
| 권한 | 사용 시점 | 목적 |
|------|-----------|------|
| 카메라 | 프로필 사진 촬영, 사진 첨부 | 사용자가 직접 촬영한 사진을 메시지에 첨부 |
| 사진 라이브러리 | 프로필 사진 선택, 파일 첨부 | 갤러리에서 이미지/파일 선택하여 전송 |
| 알림 | 앱 최초 실행 시 | 새 메시지, 멘션 등 실시간 알림 수신 |
| Face ID / Touch ID | 설정에서 활성화 시 | 자동 로그인 보안 인증 |

## 기술 스택
- React Native (Expo)
- Socket.io (실시간 메시징)
- Expo Push Notifications (FCM/APNs)
